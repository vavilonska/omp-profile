# 分享范围、脱敏与验证边界

## 来源与范围

本仓库是 2026-10-24 整理的工程工作流分享快照。来源为使用中的主控规则、公共工程技能、前端设计技能、四个自定义工程角色，以及两项本地运行时扩展。说明文档按这些来源整理，不直接复制带有私人部署记录的维护历史。

仓库保留：

- 工程协作、权限、验证与交付规则。
- 公开模型标识、角色名、技能名、工具接口和必要源码符号。
- 主控规则、两项技能、四个角色、两项扩展及其直接依赖文件。
- Windows / WSL 等有实际意义的平台条件，以及当前模型和宿主接口约束。

不包含：

- 密钥、token、认证文件、完整私人模型配置或自建服务地址。
- 个人绝对路径、内网地址、SSH 账号与密钥引用、私人项目名。
- 真实会话标识、日志、数据库、记忆库、备份、验收原始收据或历史维护材料。
- 个人化称呼与人设、业务专属角色、设备技能、OMP 二进制或宿主补丁。

## 公开副本与来源的差异

本次只写分享仓库，不修改已安装工作流或真实会话。

| 文件 | 为分享所做的处理 |
|---|---|
| `profile/APPEND_SYSTEM.md` | 移除整段本机 NAS/SSH 规则及人设专属表达；个人绝对路径改为实际 agent 配置根目录；维护文档入口改为随包说明；设备技能改为明确可选依赖；平台前提改为按实际宿主选择 |
| `profile/skills/engineering-workflow/SKILL.md` | 两处个人绝对路径改为可移植入口；Android 依赖明确为另行安装的设备技能 |
| `profile/skills/engineering-workflow/references/execution.md` | 将固定 PowerShell 宿主前提改为平台条件，其余运行责任保持 |
| `profile/skills/frontend-design/SKILL.md` | 将 Android 专属技能名改为可选的本机设备技能入口 |
| 其余角色、支持文件与扩展 | 保留来源内容，不改变模型路由或运行时算法 |

示例路径与文件职责不携带机器身份。扩展内动态生成的代理标识、原生持久化键名和通用错误文本属于实现合同，不是真实会话数据。

`.gitignore` 阻止常见凭据、配置、会话、日志和缓存意外加入仓库，但它不能代替发布前内容检查；已被 Git 跟踪的文件也不会因此自动撤出。
