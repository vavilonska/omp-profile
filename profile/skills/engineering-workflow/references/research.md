# 研究与开放设计

仅在研究实验、开放方案选择或持续负结果需要路线裁决时读取。普通既定功能实现不加载本文件。

## 目标与可调整选择

- 冻结方案前区分用户目标、评价口径、数据权限、预算和停止条件，与首批特征、模型家族、参数接口和执行版本。前者不得擅改；后者可依据证据在授权内调整。先核关键未知是否可检验，不把旧接口可表达范围当作研究边界，也不预建通用扩展平台。
- 对关键未知先说明目标指标、已有反证和待区分原因，比较能够改变决定的机制，不只微调首个方案。核对优化目标与最终评价的单位、选择过程和状态转换；例如逐行损失与去重事件收益不一致，应以最小诊断检验，不能直接认定根因。
- 实验说明增加什么信息、什么观测会否定假设。输入资格、代理指标、实现通过不等于最终目标改善；负结果不直接归因于执行模型。仅有一条合理路径时直接推进，不为形式凑多套候选。

## 持续负结果与必要适配

- 持续负结果、解释被推翻、关键机制仍无法区分或实现限制开始主导选题时，由负责人汇总跨批次证据：哪些解释被削弱、还缺哪个决定、下一实验相对其他路径的判别价值与成本。逐组有理由不等于整批优先级合理；不因尚有额度而填满，不按固定失败次数复审或逐项审批。
- 有价值的判别被实现挡住时，比较必要适配与继续原路线的证据收益、成本和旧产物复用条件。在原授权内修复当前所需路径；真正改变科学目标、权限、预算或停止条件才向用户取得决定。无权提前终止或扩项时提出具体取舍，不自行缩减目标。
- 适配沿既有权威记录保留原输入身份、失败、累计消耗和成功前缀，明确新执行身份；不重签历史、不重置额度。恢复只支持当前需要的状态转换，不按事故逐层增加白名单、审批账本或通用恢复平台。
- 用小型、隔离、可撤销的实验比较关键机制；证据与解释冲突时先作最小判别，足以决定即收敛。实验范围由待回答的问题决定；完整跑完某个辅助实验不是默认研究门槛，扩大前先说明它会改变哪项路线判断。适配取舍沿公共核心，不另设固定复审次数或证明流程。
- 长研究中的路线判断归负责人；普通实现、排障和运行交相应执行者。进度说明已取得的实质结果、未决问题和下一可观察节点，工程成功与科学结果分开报告。
