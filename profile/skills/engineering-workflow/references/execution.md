# 运行、资源与静默执行

在启动命令、子进程、浏览器、设备或长运行前读取；同一窗口已加载则复用。纯静态阅读不加载本文件。

## 入口与隔离

- 复用正式入口、已核环境和实际可用的argv。区分当前可运行入口与已清理的历史命令；不用历史runner充当依赖，不为局部烟测重建私有生命周期、监督器或调度平台。
- 启动可能写入状态的CLI、验收或探针前，按实际写入面隔离cwd、配置、数据、session/cache/temp；查询CLI不天然只读。数据隔离不代替资源互斥：仍竞争同机CPU/GPU、heavy/trading或服务租约时，沿获准权威门禁，不另建私有gate绕行。
- 公共缓存只读复用，链接目录按已有链接语义保存/恢复，不跨卷递归搬动workspace junction。运行读取中的源码、依赖和工件保持稳定；需修改时先收口受影响运行或可靠隔离，不要求无关分片全部停工。
- 先确认实际宿主终端；Windows使用PowerShell 7时，bash工具外壳不保证是pwsh，复杂引号、变量和反引号使用参数数组或临时`.ps1 -File`。其他平台使用其实际可用shell，不照搬Windows命令。不把OMP的process.execPath当Bun/Node CLI，不凭PATH同名推断系统工具。命令输出与退出状态取同次调用，不为补成功标记重跑。

## 默认静默，不丢监管

- 普通命令、构建、服务和自动化验收默认不弹窗、不抢焦点，复用已有无窗口入口。async、pty:false、输出重定向和-NonInteractive均不单独保证隐藏；不用detached/unref或丢弃输出冒充后台，保留日志、错误、取消和退出责任。
- 临时runner及后续子进程同样遵守。Windows直接创建非交互进程用CREATE_NO_WINDOW、windowsHide或对应API；已有正确入口不重复包装。WSL反向启动Windows程序需单独核对互操作入口，不能给Linux进程机械加Windows flags，关闭WSLg也不代表Windows控制台隐藏。
- Web点击、悬浮、布局、截图和Canvas验收默认独立无头浏览器，仍运行真实页面。app.relay:false只跳过relay，不保证无头；显式app.path不保证顶层headed:false转成无头参数，应沿实际入口选择。普通测试不用用户日常标签或真实profile；需要登录态时按授权使用，后台标签不等于无头。
- 用户要求展示、人工登录/交互、原生窗口/托盘/焦点验收，或已定位显示模式差异确需界面时，才打开必要窗口并简短说明。不为静默削弱验证，也不因静默入口失败就直接弹窗或修改全局WSL/终端配置。结束后关闭自建测试窗口，保留用户窗口和正式应用。规则不证明旧窗口热更新或所有外部程序绝不闪窗。

## 长运行与并发

- 批量I/O、子进程或重计算先判断依赖与瓶颈；独立工作有收益时采用有界并发、批处理、向量化或流水线。执行简单不等于串行；代理数不等于worker数，单heavy/唯一进程owner不禁止独立工程分片并行。
- 并发按可观察CPU、内存、连接池、限流和下游容量决定。余量未知选合理初值并观察，不编造额度、不永久退回单路、不铺满输入或相乘嵌套上限。保持有序提交、错误传播、取消及资源释放。
- 高频取消/截止检查轻量；RSS、数据库和进程树按真实响应需要采样，不放进逐值热路径。显著等待时用阶段进度、耗时和负载区分正常计算、依赖和异常；下一次昂贵运行必须能区分剩余关键原因，不能只盲目延长超时。
- 以真实生命周期设置期限，避免默认短超时杀正常长任务；无截止要求时用受监管的长任务方式。负责人自定时限可在用户预算内依证据调整，不暗改冻结记录或越用户上限。启动后继续独立工作，无可推进事项才沿正式等待入口等待。
- 实际进程owner跟踪至退出，不用子代理终态、Guest退出或父进程退出替代其他实际消费者/互操作helper的停止证明。只对本次真实存在的进程树和控制边界取证，不凭假想进程扩建监控。临时工具保留到最后消费者完成再清理，更新可运行入口并留下必要去敏证据。
